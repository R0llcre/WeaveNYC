# Archive

这个目录用于保存不应继续堆在项目根目录、但仍有追溯价值的材料。

## Contents

- `legacy-slides/`
  - 旧的 personas / slide / visual deliverables
  - 相关 `pptxgenjs` 脚本和旧版 `package.json`

- `project-history/`
  - midterm proposal
  - professor notes
  - 保留版 speaking script

## Rule

- 当前项目开发默认不读取本目录。
- 只有在需要追溯历史决策、复用旧交付物、或查看课程背景时才进入本目录。
