## DESIGN AT A GLANCE

### Layout Type
**Comparison Table** — Structured 4×4 grid with row headers and three persona columns

### Visual Approach
```
┌────────────────────────────────────┐
│ ONE LARGE GLASS CONTAINER          │
│ ├─ 4 rows (Header, Who, Goal, Value)
│ └─ 4 columns (Labels, Need Seeker, Helper, Anchor Admin)
│
│ Each persona gets a COLOR-CODED column
│ Each category gets a ROW
│ Content is SCANNABLE and PROFESSIONAL
└────────────────────────────────────┘
```

### Personas (Columns)
1. **Need Seeker** (Blue #2563EB)
   - Low-income/immigrant residents
   - Find help ASAP, privately, quickly
   - Value: Zero friction, anonymous, no tracking

2. **Helper** (Green #10B981)
   - Volunteers, neighbors, community
   - Post offers, match safely, get alerts
   - Value: Smart matching, safety, trust signals

3. **Anchor Admin** (Purple #8B5CF6)
   - NGO/church staff, coordinators
   - Moderate, configure, review, audit
   - Value: Full visibility, compliance, control

### Premium Features
- ✓ Liquid glass container (88% opaque white with soft shadow)
- ✓ Colored header rows (20% persona color opacity)
- ✓ Subtle grid borders (1pt, 85% transparent light gray)
- ✓ Blue/cyan gradient background (visible through glass)
- ✓ Color-coded checkmarks in "Our Value" row
- ✓ Clean, scannable typography hierarchy

## DESIGN DIFFERENTIATION

### Why This Approach is Unique

| Slide | Style | This Slide's Difference |
|-------|-------|------------------------|
| P1 | Asymmetric Cards | Single structured container, not scattered |
| P2 | Center Image + Labels | Text-based table, not image-centric |
| P3 | Pyramid Grid | Rectangular grid, not hierarchical triangle |
| **P4 (This)** | **Comparison Table** | **Structured, scannable, data-driven** |

### Key Differentiators
- **Structured:** Not scattered or visual pyramids; clean grid organization
- **Table-Based:** Professional data-table aesthetic
- **Single Container:** Everything in ONE glass card (not multiple floating elements)
- **Comparative:** Side-by-side persona view (easy to contrast)
- **Professional:** Suggests research and intentional design

## TROUBLESHOOTING QUICK GUIDE

| Problem | Solution |
|---------|----------|
| Glass effect not visible | Reduce white veil transparency (92% → 85%) |
| Grid borders invisible | Increase opacity (85% transparent → 70%) |
| Text too small | Increase font size (9pt → 10pt) |
| Content wrapping weird | Increase row height (1.0" → 1.1") |
| Headers too light | Reduce header opacity (20% → 10%) |
| Shadow too harsh | Reduce blur radius (40pt → 35pt) |
| Font not rendering | Ensure Calibri installed; add fallback |

See PERSONAS_SLIDE_GUIDE.md for detailed troubleshooting section.

## DESIGN PHILOSOPHY SUMMARY

### Why a Comparison Table?
1. **Scannable** — Natural reading flow (left-to-right, top-to-bottom)
2. **Professional** — Data-table aesthetic suggests research
3. **Dense** — Fits all content without visual overload
4. **Comparative** — Easy to contrast personas side-by-side
5. **Structured** — Communicates intentional, user-centric design

### Why These Colors?
- **Blue (Need Seeker):** Calm, trust, stability → vulnerable users need comfort
- **Green (Helper):** Growth, positive action → empowering volunteers
- **Purple (Anchor Admin):** Authority, leadership → organizational oversight

### Why Premium Glass Aesthetic?
- **Consistency** — Matches cover slide design language
- **Sophistication** — Communicates quality and polish
- **Depth** — Layered transparency creates visual interest
- **Approachability** — Soft, not harsh; friendly, not corporate
