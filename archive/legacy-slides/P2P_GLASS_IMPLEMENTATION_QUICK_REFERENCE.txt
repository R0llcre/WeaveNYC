5-LAYER GLASS CARD PATTERN (Standard Template)
═══════════════════════════════════════════════════════════════════════════════

For any card at position (x, y) with dimensions (w, h):

LAYER 1: OUTER GLOW HALO
────────────────────────
Position:     x-0.08,  y-0.08
Size:         w+0.16,  h+0.16
Fill:         NONE
Shadow:       type='outer' | color='000000' | blur=18
              offset={x:0, y:6} | angle=135 | opacity=0.05

LAYER 2: MAIN GLASS BODY
────────────────────────
Position:     x,  y
Size:         w,  h
Fill:         color='FFFFFF' | transparency=50  ◄── KEY (50% opaque)
Border:       NONE
Radius:       0.15"

LAYER 3: GLASS BORDER DEFINITION
────────────────────────────────
Position:     x,  y
Size:         w,  h
Fill:         NONE
Border:       color='FFFFFF' | width=1.5pt | transparency=45
Radius:       0.15"

LAYER 4: TOP-EDGE LIGHT CATCH (Refraction simulation)
──────────────────────────────────────────────────────
Position:     x+0.05,  y+0.05
Size:         w-0.10,  h=0.12"
Fill:         color='FFFFFF' | transparency=70
Border:       NONE
Radius:       0.15"

LAYER 5: INNER SHIMMER HIGHLIGHT (Bottom glow)
───────────────────────────────────────────────
Position:     x+0.10,  y+(h-0.25)
Size:         w-0.20,  h=0.08"
Fill:         color='FFFFFF' | transparency=55
Border:       NONE

═══════════════════════════════════════════════════════════════════════════════
TRANSPARENCY VALUE REFERENCE
═══════════════════════════════════════════════════════════════════════════════

Transparency Setting → Opacity %  → Visual Effect
────────────────────────────────────────────────────────
transp=18            → 82% opaque → Header bands (strong color)
transp=25            → 75% opaque → Glass badges
transp=40            → 60% opaque → Connectors
transp=45            → 55% opaque → Card borders
transp=50            → 50% opaque → Main glass body ◄── KEY
transp=55            → 45% opaque → Shimmer highlight
transp=60            → 40% opaque → Separators
transp=62-72         → 28-38%     → Background blobs
transp=65-72         → 28-35%     → Blob variations
transp=70            → 30% opaque → Top light catch
transp=80-93         → 7-20%      → Subtle overlays

RULE: Never use decimals. Always use INTEGER only.
  CORRECT:   transparency: 50
  WRONG:     transparency: 0.50

GRADIENT OVERLAY (Left-to-Right Flow)
═══════════════════════════════════════════════════════════════════════════════

Divide canvas into 4 zones (each 2.5" wide):

Zone 1 (x=0-2.5"):      color='FFFFFF' | transp=95 (5% opaque, very light)
Zone 2 (x=2.5-5.0"):    color='FFFFFF' | transp=92 (8% opaque, light)
Zone 3 (x=5.0-7.5"):    color='FFFFFF' | transp=90 (10% opaque, medium)
Zone 4 (x=7.5-10.0"):   color='FFFFFF' | transp=88 (12% opaque, darker)

Effect: Subtle increase in opacity from left to right creates visual flow

═══════════════════════════════════════════════════════════════════════════════
CONNECTING LINES & ARROWS (P2P Flow)
═══════════════════════════════════════════════════════════════════════════════

FORMAT: Rectangle with rotation + Text arrow

Line 1 Properties:
  Type:      prs.ShapeType.rect
  Position:  x, y
  Size:      w (short) | h (thin, ~0.08")
  Color:     Derived from source node
  Transp:    40 (60% opaque for visibility)
  Rotate:    -5 to +5 degrees for diagonal flow

Arrow Text:
  Glyph:     "→" (U+2192 RIGHT ARROW)
  Position:  offset by +0.1-0.2"
  Font:      Calibri or Segoe
  Size:      14pt
  Color:     Complementary to line
  Transp:    40

═══════════════════════════════════════════════════════════════════════════════
APPROVED SHADOW FORMAT
═══════════════════════════════════════════════════════════════════════════════

Standard shadow for glass halos:
{
  type: 'outer',
  color: '000000',        ◄── Black shadow
  blur: 18,               ◄── Blur radius in points
  offset: { x: 0, y: 6 }, ◄── Vertical offset downward
  angle: 135,             ◄── Angle in degrees (bottom-right)
  opacity: 0.05           ◄── Very subtle (5% of black)
}

Subtle shadow for badges:
{
  type: 'outer',
  color: '000000',
  blur: 8,
  offset: { x: 0, y: 2 },
  angle: 135,
  opacity: 0.03
}

═══════════════════════════════════════════════════════════════════════════════
COMMON MISTAKES TO AVOID
═══════════════════════════════════════════════════════════════════════════════

✗ Using transparency decimals (0.50 instead of 50)
✗ Including "#" in color codes ('#C7D2FE' instead of 'C7D2FE')
✗ Forgetting to add white veil overlay
✗ Not layering all 5 glass components
✗ Using wrong transparency for main body (must be exactly 50)
✗ Positioning elements outside 10"×5.625" canvas
✗ Inconsistent corner radius across cards
✗ Shadow blur too high (obscures content)
✗ Blobs with transparency too low (becomes opaque)
✗ Text color not contrasting with background
