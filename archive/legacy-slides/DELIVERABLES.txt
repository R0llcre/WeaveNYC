HOW TO USE
═══════════════════════════════════════════════════════════════════════════════════

Opening the Slide
  1. Open personas_slide_new.pptx in:
     - Microsoft PowerPoint (2010+)
     - Google Slides
     - LibreOffice Impress
  2. Slide displays as standalone presentation
  3. Can be inserted into main deck as needed

Customizing the Slide
  1. Edit personas_slide.js with desired changes:
     - Colors: Modify PERSONAS array accentColor values
     - Text: Update who, goal, value strings
     - Layout: Adjust positioning constants
     - Typography: Change font/size/color in addText() calls
  2. Save the file
  3. Run: node personas_slide.js
  4. New personas_slide_new.pptx is regenerated

Integrating into Main Deck
  Option A: Copy-paste slide from personas_slide_new.pptx
  Option B: Use python-pptx to programmatically insert
  Option C: Export as PDF for standalone distribution
