TRANSPARENCY & LAYERING (Z-Order)
═════════════════════════════════════════════════════════════════════════════════

Layer 0 (Canvas Background): White (default)

Layer 1: Background Ellipses (Behind everything)
  - 4 overlapping ellipses with high transparency
  - Create gradient effect without native gradient support
  - Z-order: Rendered first (background layer)

Layer 2: Glass Containers (Floating Cards)
  - 2 rounded rectangles with transparency
  - Appear to float above background due to shadow
  - Z-order: Rendered after ellipses

Layer 3: Text & Accents (Top Layer)
  - All typography
  - Divider lines
  - Badges and icons
  - Z-order: Rendered last (visible on top)

Rendering Strategy:
  1. Add all background ellipses first
  2. Add glass card containers
  3. Add all text elements last
  - PptxGenJS renders in addition order
